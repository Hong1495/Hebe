# Hebe 1.1.0 — First public release

A focused desktop Markdown editor for Apple Silicon Macs (macOS 13+).

- Live Markdown editing with source mode, editable tables, Mermaid, KaTeX and local images.
- Multiple tabs, native menus, outline, themes, focus mode and typewriter mode.
- Preserve tab undo history, selection and scroll position within a session.
- Protect unsaved work when quitting or restarting for an update.
- Resolve relative images during export and support document images on external volumes.
- Add Bee-inspired signed updates with an orange window-control indicator, release-note popover, automatic checks, download progress and explicit restart.
- Publish English and Chinese documentation, MIT license and reproducible release scripts.

Download the DMG and drag Hebe.app to Applications. This release is ad-hoc signed but not Apple-notarized. Pandoc is required for export; PDF additionally requires XeLaTeX. Only Apple Silicon macOS binaries are included.
