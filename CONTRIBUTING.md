# Contributing

Keep changes focused on reliable, quiet Markdown editing. Open an issue before large changes. Include minimal Markdown examples for rendering bugs.

Run `npm test`, `npm run build` and `cargo test --manifest-path src-tauri/Cargo.toml` before sending a pull request. Test native changes inside Tauri. Never commit private signing keys, local documents, build outputs or installed app bundles.

Contributions are provided under the MIT license.
